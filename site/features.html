What is in Muster.

Each item has one sentence and one label. The label says whether it is in the release.

Delivery

  • Task board and sprints. A task board with sprints. Agents and people read and write the same rows. [In Muster]
  • Releases. Each release has a record with a changelog. [In Muster]

Clients and money

  • Client portal. Clients see their own projects, tasks, invoices, and messages. [In Muster]
  • Proposals. Proposals are stored as records. [In Muster]
  • Invoices and Stripe billing. Invoices are stored as records and billing runs through Stripe. [In Muster]
  • Deals and expenses. Deals and expenses are stored as records. [In Muster]

Knowledge and assets

  • Knowledge base. A searchable set of pages. It is not in a clean install. [Partly in Muster]
  • DAM and brand books. Asset library and brand books. Only part of this is in the release. [Partly in Muster]

Operations

  • AI cost ledger. A ledger of what the agents spent. Only part of this is in the release. [Partly in Muster]
  • Analytics. Site and delivery analytics. Only part of this is in the release. [Partly in Muster]
  • Infra dashboards. Dashboards for infrastructure. Only part of this is in the release. [Partly in Muster]
  • Tools launchpad. A page that launches the studio tools. Only part of this is in the release. [Partly in Muster]

Internal tools

  • Photo galleries. Private client albums. Read the case study. [Internal only, not in the release]
  • Claude rules with toggles. Rules for Claude that staff switch on and off. [Internal only, not in the release]
  • Heatmap tiles. Click and scroll tiles from first-party beacons. [Internal only, not in the release]

Three labels. In Muster means it is in the release. Partly in Muster means only part of it is. Internal only means we use it and it is not in the release. The portal is not yet public, so a clean install does not show every item here. See the install notes.
